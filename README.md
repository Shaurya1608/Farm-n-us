# Farm 'N' Us (Farmnus)

> **Turn Land Into Living Farms**  
> A venture by GSPCL (formed under the Government of India's Central Sector Scheme)  
> Ghaghra, Gumla, Jharkhand, India.

Farm 'N' Us helps individuals, families, and landowners turn underutilised land into productive, high-value, living farms — making sustainable agriculture accessible and manageable through end-to-end models (Build, Build + Manage, and Support).

---

## 🌾 Overview & Features

- **The Living Connection Pipeline**: An interactive 6-stage biological journey (Soil → Seed → Plant → Farm → Harvest → Food).
- **Three Partnership Models**:
  1. **Build**: Turnkey farm development, precision micro-irrigation, and handover.
  2. **Build + Manage**: End-to-end co-farming with full agronomy oversight, labor, and direct-to-market linkage.
  3. **Support**: Advisory, irrigation maintenance, and seasonal manpower.
- **Ecological Action & Impact Metrics**: Tracking native tree planting, water conservation (up to 90% via micro-drip), and rural livelihoods.
- **Harvest Traceability**: From our farms straight to households and culinary partners.

## 🛠️ Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

To create an optimized production build:

```bash
npm run build
```
